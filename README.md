# NextLevel Gaming Community 🎮

A responsive gaming community and game showcase website built using **HTML5 and CSS3 only**.

## Features
- Home, Games, Community, and About sections
- Six featured games with links to their official websites
- Responsive layout for desktop, tablet, and mobile
- CSS-only animations, hover effects, and original CSS artwork
- Accessible navigation and reduced-motion support
- No JavaScript

## Technologies
- HTML5
- CSS3

## Project Structure
```text
nextlevel-gaming-website/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Run Locally
1. Download or clone the repository.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Upload the project files to your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your publishing branch (usually `main`) and the `/ (root)` folder.
5. Save and wait for GitHub Pages to publish.

Future commits to the configured branch will trigger a new deployment.
